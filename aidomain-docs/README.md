# AiDomain · 边缘 AI 视觉分析

艾域智能科技（Ai Domain Intelligence）是一家专注**边缘 AI 视觉分析**的整体方案商，提供从数据集管理、模型训练到边缘部署的完整闭环。官网：**https://www.aidomainhub.cn**

> Edge AI vision solutions: data management, model training and edge deployment in one closed loop.

## 产品矩阵

| 产品 | 定位 | 关键能力 |
|---|---|---|
| **AiDStudio** | 数据集管理平台 | 数据资产化 · 自研标注画布（SAM 智能修正）· 主动学习迭代标注 · AI 模型训练（MLflow 追踪）· Docker Compose 一键部署 |
| **AiDBox** | 智能视觉分析盒 | INT8 16 TOPS NPU · 16 路 1080p@30fps 实时分析 · 浏览器端零代码编排 · MQTT / HTTP 结构化事件 · ≤16W 无风扇宽温 |
| **AiDCam** | 边缘 AI 智能相机 | 4K IMX415 采集 · 双码流 RTSP 直连 NVR · NPU 实时检测 · GPIO / LED / 语音告警联动 · 无需服务器独立值守 |

## 典型场景

- 智慧工厂：PPE 佩戴检测、区域入侵、安全帽识别
- 智慧工地：周界防护、越线告警
- 智慧油站 / 商铺 / 家庭周界：单点值守、事件联动
- 工业质检与安防监控：模型定制训练、边缘部署

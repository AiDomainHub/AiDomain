# AiDBox 智能视觉分析盒

一体化边缘 AI 视频分析设备：视频接入、解码、推理、跟踪、行为分析与事件推送全部在本地完成，数据不出设备。

## 核心参数

| 项目 | 参数 |
|---|---|
| AI 算力 | INT8 16 TOPS（INT4 32 TOPS / FP16 4 TFLOPS） |
| 视频解码 | 16 路 1080p@30fps（H.264 / H.265） |
| 视频编码 | 10 路 1080p@30fps |
| 内存 / 存储 | LPDDR4 8 GB（可选 16 GB）· eMMC 32 GB（可选 256 GB） |
| 功耗 | ≤16W，无风扇被动散热 |
| 工作温度 | -20℃ ~ +60℃ |
| 尺寸 / 重量 | 200 × 160 × 43.8 mm / 1426 g |

## 关键能力

- 浏览器端**零代码可视化编排**（模型导入 → 视频接入 → 规则 → 事件推送）
- 主流 AI 检测引擎 + ByteTrack 多目标跟踪
- GroundingDINO 开放词汇检测（无需训练识别新类别）
- Qwen VLM 视觉语言提示词判断
- MQTT / HTTP 结构化事件输出，对接第三方平台

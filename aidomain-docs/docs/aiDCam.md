# AiDCam 边缘 AI 智能相机

面向园区、工地、商铺与家庭周界等泛安防场景的单点值守智能相机：视频采集、AI 检测与告警联动全部在相机前端完成，无需服务器。

## 核心参数

| 项目 | 参数 |
|---|---|
| 图像传感器 | Sony IMX415，1/2.8"，约 846 万有效像素（4K UHD），STARVIS 低照度 |
| AI 算力 | NPU INT8 3 TOPS |
| 视频编码 | H.264 / H.265 主/子双码流 |
| 推流协议 | 标准 RTSP（TCP/UDP），支持鉴权 |
| 镜头 | 4mm 广角定焦 |
| 供电 | DC 12V |
| 工作温度 | -20℃ ~ +65℃ |

## 关键能力

- 4K 采集 · 双码流推流，RTSP 直连 NVR / 第三方平台
- NPU 实时检测：人 / 车 / 火焰 / 安全帽等按场景配置
- 区域入侵、越线规则 + 连续帧确认防误报
- 告警联动：GPIO（光耦隔离）/ LED 频闪 / 语音播报 / 抓图留证
- Web 远程管理、OTA 升级、推理模型热切换

# 系统架构（概览）

AiDomain 提供"数据 → 训练 → 边缘部署"三层闭环方案，满足工厂、工地、油站、园区等场景的视频 AI 分析需求。

## 三层结构

```
┌──────────────────────────────────────────────┐
│ 数据层 · AiDStudio（本地/私有化部署）          │
│  数据导入 → 标注（SAM 辅助）→ 数据集管理 → 训练 │
└──────────────────┬───────────────────────────┘
                   │ 模型导出 ONNX / bmodel / rknn
┌──────────────────▼───────────────────────────┐
│ 边缘层 · AiDBox / AiDCam（本地推理）          │
│  视频接入 → AI 检测 → 跟踪 → 规则判定         │
└──────────────────┬───────────────────────────┘
                   │ MQTT / HTTP 事件
┌──────────────────▼───────────────────────────┐
│ 应用层 · 告警与联动                            │
│  语音播报 / LED / GPIO · 第三方平台 / 企业微信  │
└──────────────────────────────────────────────┘
```

## 关键设计

- **数据不出厂**：采集、训练、推理均在本地完成，满足制造业数据合规要求
- **复用存量设备**：支持 RTSP / ONVIF 协议，旧摄像头无需更换
- **模型持续迭代**：误报难例回流 AiDStudio 重训，模型越用越准
